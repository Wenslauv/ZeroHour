# ZeroHour

A small first-person shooter framework in **Unreal Engine 5.8 and C++**: an arena, a player character,
input, and the groundwork for weapons, enemies and a HUD. Built as a portfolio project and kept
deliberately extensible — new weapons, enemies and level rules plug in without touching the core.

**Status:** work in progress, built in a five-day sprint (day 1 of 5).

## Features

Done:

- `AZhPlayerCharacter` on top of the template character, with arena-shooter movement tuning.
- Enhanced Input: fire, weapon switching, weapon slots and interact actions bound in C++.
- **Procedural arena generator** — an editor Python script that builds a random blockout arena from
  a seed and a set of criteria (size, platforms with ramps, cover, pillars, jump blocks), with spacing
  rules that keep the floor connected for the player and the AI. Same seed, same layout.
- Debug tooling: `UZhCheatManager` console commands and the `LogZeroHour` log category.
- Architecture notes in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Planned for the sprint:

- [ ] Data-driven weapons: hitscan shotgun and projectile rocket launcher (`UPrimaryDataAsset`).
- [ ] `UZhHealthComponent` shared by the player and enemies; pickups.
- [ ] Enemies: Behavior Tree AI with custom C++ tasks, melee and ranged types.
- [ ] UMG HUD driven by component delegates.
- [ ] Door and key system in Blueprint on top of a C++ interface.
- [ ] Editor Utility Widget that validates a level for designers.
- [ ] Automation tests and an Unreal Insights profiling pass.

## Controls

The layout is trackpad-friendly; a mouse works the same way.

| Action | Key |
| --- | --- |
| Move / jump | `W` `A` `S` `D` / `Space` |
| Look | Mouse or trackpad |
| Fire | Click or `Left Ctrl` |
| Previous / next weapon | `Q` / `E` |
| Weapon slots | `1`, `2` |
| Interact | `F` |
| Console | `~` |

## Build and run

Requirements: Unreal Engine 5.8, Git LFS, and a C++ toolchain supported by UE 5.8 (on macOS: Xcode 26.0–26.1.1;
Xcode 26.4 is not compatible). Developed on macOS with Apple Silicon and JetBrains Rider.

```bash
git lfs install
git clone https://github.com/Wenslauv/ZeroHour.git
```

1. Open `ZeroHour.uproject` in Rider (or generate project files for your IDE).
2. Build the `ZeroHourEditor` target in the `Development Editor` configuration and launch it.
3. Press Play: the editor starts in `Content/Maps/L_Arena`.

## Arena generator

The arena is produced by [`Content/Python/build_arena.py`](Content/Python/build_arena.py).
In the editor's Output Log (Cmd mode):

```
py build_arena.py              # new random layout; the seed is printed to the log
py build_arena.py --seed 1234  # reproduce a layout
```

Then run **Build → Build Paths** to regenerate the NavMesh and save the level. The generation criteria
(arena size range, obstacle counts, spacing, ramp angle) are constants at the top of the script.

## Debug commands

Open the console with `~` in Play mode:

| Command | Effect |
| --- | --- |
| `God` | Toggles invulnerability (built into `UCheatManager`) |
| `ZhGiveAmmo` | Refills ammo (stub until weapons land) |
| `Log LogZeroHour Verbose` | Shows verbose ZeroHour logs |

## Project layout

```
Source/ZeroHour/     C++ module
  ZeroHour*          base layer generated by the First Person template
  Zh*                ZeroHour's own code
Content/Input/       input actions and mapping contexts
Content/Maps/        levels
Content/Python/      editor scripts (arena generator)
docs/                architecture notes
```

Shared template content (`Characters/`, `Weapons/`, `LevelPrototyping/`) is used as placeholder art.
